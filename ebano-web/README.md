# ébano | Sitio web estático

Abrir `index.html` en el navegador. Archivos: `index.html`, `styles.css`, `app.js`, `assets/marca/` y `assets/fotos/`. Compatible con hosting estático/cPanel.

## IMPORTANTE: Cotizaciones
El formulario usa `mailto:` y **NO envía directamente desde el servidor**: abre el correo del usuario con la solicitud prellenada, que el usuario debe enviar. Para recepción automática sin abrir la app de correo se debe configurar un endpoint de formulario (PHP SMTP/servicio externo) con validación antispam y confirmación de éxito. El mensaje actual evita afirmar que el correo ya se recibió.

Destinatario configurado: hola@ebano.dharmamedia.cl. No se incluye WhatsApp por falta de número confirmado.
